# Shawcliffe Digital — Internal Operations System

This folder is the internal playbook for running Shawcliffe Digital: how we sell, build, deliver,
support, and grow client work. It's written for a two-person husband-and-wife team, not a corporate
agency. If a process here feels heavy, cut it — the whole point is staying lean.

**Legal note:** Section 8 (legal/risk) is a plain-English draft outline only. It is not legal advice.
Have a real lawyer review anything before you use it as an actual contract.

## How to use this

- These are living documents. Update them when reality changes — don't let them rot.
- "Must-have now" = needed before/while taking your next client. Do this first.
- "Nice-to-have later" = useful once you have 3+ active clients or real volume. Skip for now.
- Every doc has copy/paste templates where useful. Use them, don't rewrite from scratch each time.

## First 10 Documents to Build Before Taking on More Clients

Don't build all of this on day one. In priority order:

1. **Discovery questionnaire** (general local business version) — [04](04-discovery-templates.md)
2. **Proposal template** — [05](05-proposals-and-pricing.md)
3. **Pricing sheet** (your 4 core packages + support tiers) — [05](05-proposals-and-pricing.md)
4. **Service agreement / SOW draft** (send to a lawyer before use) — [08](08-admin-legal-metrics-tools.md)
5. **Client onboarding checklist + welcome email** — [06](06-project-delivery.md)
6. **Launch checklist** — [06](06-project-delivery.md)
7. **Monthly support scope doc** (what's included/not) — [07](07-client-training-and-support.md)
8. **Lead/project tracker** (a spreadsheet is enough) — [08](08-admin-legal-metrics-tools.md)
9. **Discovery call script** — [09](09-templates-and-scripts.md)
10. **Client training one-pager for your dashboard product** — [07](07-client-training-and-support.md)

Everything else in this folder is here so you don't have to invent it later — build it when you actually
need it, not before.
