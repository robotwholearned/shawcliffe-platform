# 10. First 90 Days Implementation Plan

Goal: start selling and delivering without drowning in documentation you don't need yet.

## Week 1 — Sell-Ready Basics

- [ ] Write the general discovery questionnaire ([04](04-discovery-templates.md)) — done, adapt as needed
- [ ] Write the proposal template + pricing sheet ([05](05-proposals-and-pricing.md)) — done, adapt as needed
- [ ] Set up the lead/project tracker spreadsheet ([08](08-admin-legal-metrics-tools.md))
- [ ] Draft the service agreement / SOW and send it to a lawyer for review ([08](08-admin-legal-metrics-tools.md))
- [ ] Set up a shared password manager and file storage structure

## Weeks 2–4 — Delivery-Ready Basics

- [ ] Onboarding checklist + welcome email in use for the next client ([06](06-project-delivery.md), [09](09-templates-and-scripts.md))
- [ ] Launch checklist finalized ([06](06-project-delivery.md))
- [ ] Monthly support plan scoped and priced ([07](07-client-training-and-support.md))
- [ ] Client training one-pager drafted for whichever product you sell most (likely the
      dashboard/notification app)
- [ ] Run one full client through intake → launch using these docs, note what's missing or clunky

## Month 2 — Fill the Gaps You Actually Hit

- [ ] Add any vertical-specific discovery questionnaires you actually need (tradesperson, seller,
      church, etc. — [04](04-discovery-templates.md))
- [ ] Build out the QA checklist into your actual pre-launch habit, not just a doc ([06](06-project-delivery.md))
- [ ] Start tracking the core metrics monthly ([08](08-admin-legal-metrics-tools.md))
- [ ] Set up your referral ask as a habit at every successful launch

## Month 3 — Systematize and Retain

- [ ] Review your first 2–3 client renewals — refine the recurring pricing tiers based on real
      support time spent ([07](07-client-training-and-support.md))
- [ ] Formalize the upsell check-in cadence (quarterly) for existing clients
- [ ] Revisit this whole folder — delete or simplify anything you haven't touched, add anything
      you kept improvising by hand instead

**The point of this plan:** you should be able to sell and deliver one real client using only Week 1
+ Weeks 2–4 output. Everything after that gets built from actual friction, not speculation.
